# Ý tưởng ngẫu hứng

File này dùng để ghi nhanh các ý tưởng gameplay/UI chưa cần chốt thiết kế. Nội dung có thể thô, rời rạc, và sẽ được refine sau.

## Gameplay / Progression

- Item chìa khoá để mở khoá level tiếp theo.
- Mức chơi khó/dễ.

## Ghi chú thêm

- Bổ sung ý tưởng mới trực tiếp vào file này khi nghĩ ra.
